01Locked facts

  • Quality generator: WorldStereo memory-DMD FP8 on one RTX 3090. Not Wan 2.1 I2V, not Matrix-3D, not LightX2V.
  • Default mode is Joint: 20 frames per kept rail, samples of 20 that share memory. Per rail is 21 front frames each. Seed 1024.
  • Depth is one MoGe-2 cache. Geometry, Plot Camera, the guide, and HiRes all read it. A stale rail must be re-plotted before Generate.
  • The guide is a mesh of that depth, textured with the 8K panorama. The floor is filled where the panorama saw it. Thin mask streaks are removed and feathered.
  • HiRes all is a separate click. It composites the 8K panorama, the shared layer, then the WorldStereo frame. 4x-UltraSharp fills only the holes.
  • Four straight rails, optional 5th. Empty prompt blocks Generate.
  • Do not use SeedVR as the sharpness path. Do not shell out to ComfyUI.
  • Preview is render, mask (white = empty), and keyframe. Reconstruct: Keep / Ditch / Re-gen. The dataset is known-pose COLMAP.

02How many camera sets

There is no count that produces a perfect scan. Extra rails do not raise per-view fidelity — every path reprojects the same MoGe depth. They buy explorable volume (SplatKit measured six paths reaching 1.12 from the anchor vs 0.80). Glass, mirrors, and depth silhouettes stay MoGe failures no matter how many drones you add. Shorter travel per rail plus more rails beats one long rail: 8K coverage decays as you leave the origin (garden example: 0.85 at frame 0 → 0.49 at frame 80).

07HiRes

HiRes all does not repaint the whole frame. Where the MoGe-2 mesh can see the 8K panorama, those pixels stay. 4x-UltraSharp is used only in the holes, after the shared layer.

  • The panorama must be the same file Geometry and Plot Camera used.
  • Depth comes from outputs/<scene>/depth, not a second MoGe pass.
  • If the panorama is not 8192 wide, Quality HiRes refuses.

08Acceptance · risks · do not

  • Four rails, each with its own rails/rail_XX.json.
  • Optional 5th rail. Rail 1 stays.
  • Empty prompt blocks Generate.
  • Preview is render, mask, and keyframe. Generate does not start HiRes.
  • Reconstruct Ditch excludes a rail. Re-gen targets one rail. The newest dataset is shown when loading finishes.
  • COLMAP images are WorldStereo pinholes plus six gnomonic faces of the 8K panorama.
  • Train starts after WorldStereo has exited, Gaussian budget about 3M, on one 3090.
  • Suggest paths fills four distinct archetypes, all starting at the star.
  • One 3090: finish WorldStereo before HiRes all.
  • Do not load Skywork .ckpt without convert_pano_lora.py.
  • Do not skip HiRes and treat the WorldStereo frame as the 8K image. Do not use SeedVR instead of HiRes.
  • Do not enable base_mode=wan as splat default. Do not run PanoLRM.
  • Do not claim extra rails fix glass. Do not default frames to 0-15,16-/8 while the graph is 0-80/2.
  • Do not auto-start HiRes after Generate.
  • Do not run vanilla COLMAP pinhole on raw ERP. Do not un-bend points3D to flatten a bowed splat.
